# Separador-de-scan
Projeto de automatização de arquivamento de processo de devolucao 

## Problema inicial
Na empresa em q eu trabalho preciso fazer o arquivamento dos processo de devoluções, mas isso é um processo demorado e q exige mt tempo pois os processos tinham q ficar separados por cliente

## Soluçao
Para resolver essa questao criei um script em python q le um arquivo .PDF com varios processos de uma vez e separa os processos
por paginas com os cliente e deus devidos documentos do processo
